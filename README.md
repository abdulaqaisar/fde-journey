# FDE Journey

Daily learning companion for the AI → FDE → Architect roadmap.

## Run

```bash
npm install
npm run dev
```

## What it does

- Shows the next topic from the 560-item learning queue
- One-click copy of your reusable daily teaching prompt
- Per-topic notes + progress saved in `data/progress.json`
- Progress + mark done / continue through levels

Progress is written into the project repo while `npm run dev` is running, so refresh keeps your place.
